Опис

Один пункт у рядку. Це з'явиться як буллет-список на картці курсу.

Кнопка та оплата

Посилання-запрошення у приватну Telegram-групу. Клієнт побачить його на сторінці подяки після оплати.

Це URL який треба вставити у налаштування кнопки WayForPay у полі «Return URL» / «URL повернення». Клієнт потрапить сюди після успішної оплати.

Можна використовувати або варіант з ID (короткий), або з slug (зрозумілий, не змінюється при перестановці курсів). Раджу варіант з slug — він стабільний.

Фото обкладинки

Якщо завантажили файл вище — поле заповниться автоматично. Можна також вказати готовий URL зображення.

Превʼю:

📄 Сторінка курсу: …
👁️ Переглянути

Якщо вимкнено — кнопка «Обрати курс» на лендингу одразу відкриває форму оплати.
Якщо увімкнено — веде на /course.html?slug=... з повним описом.

Блоки сторінки

💡 Підказка: Для тексту підтримується форматування **жирний**, *курсив*, # заголовок, - список, > цитата, [текст](url). Між абзацами — порожній рядок.
