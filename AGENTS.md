# For any AI coding agent

Same brief regardless of which assistant opens this folder (Claude, Copilot, Cursor, Codex, Bolt, Lovable, etc.).

**Read [`CLAUDE.md`](./CLAUDE.md) first.** It contains the product context, design system, hard rules, and open follow-ups. The rules in CLAUDE.md apply to you.

Quick recap of the non-negotiables:

- Do **not** redesign sections, change palette/fonts, switch from formal "ви", or rebuild the mobile hero. Treat the file as a baseline.
- Do **not** introduce JavaScript, build steps, or external CSS/JS files. The page is intentionally a single static HTML + `assets/`.
- Do **not** delete files in `assets/` even if they look unused.
- Reply to the user in Ukrainian, in plain language without jargon.
- For deploy: hand the folder back to the user; do not push to Vercel yourself.
